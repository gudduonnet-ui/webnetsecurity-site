Webnet Security Solutions - Final website package with product images & Bengali support
--------------------------------------------------------------------------------------
Files included:
- index.html
- styles.css
- site.js
- images: dome.jpg, bullet.jpg, hdd.jpg, wire.jpg, smps.jpg, hero.jpg, logo-white.png, favicon.png, brand1.png, brand2.png, brand3.png

How to deploy:
1) Netlify (recommended): https://app.netlify.com/drop -> drag & drop the unzipped folder
2) Vercel CLI: cd to folder and run: vercel --prod

Edit content:
- Open index.html to change phone/company/prices/texts.
- Replace placeholder images with real photos (same filenames) if desired.

Notes:
- Language selector supports English, Hindi and Bengali. Choose from the dropdown to switch texts for hero & package lists.
- For production contact form, replace demo handler in site.js with Formspree or backend endpoint.
